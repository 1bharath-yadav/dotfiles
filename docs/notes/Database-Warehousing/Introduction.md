**What is DBMS?** #flashcard

- Software for storing, retrieving, and managing data.
- Eliminates many problems of file systems.
- Provides security, concurrency, backup, and integrity.
- Examples: MySQL, PostgreSQL, Oracle.

**DBMS History Timeline** #flashcard

- File Systems → Hierarchical → Network → Relational → Object-Oriented → NoSQL/Cloud.
- Relational Model proposed by Edgar F. Codd in 1970.
- SQL became the standard language for relational databases.
- Modern systems include cloud and distributed databases.
<!--ID: 1782045116636-->

**Which SQL commands modify the Data Dictionary?** #flashcard

- DDL commands modify the Data Dictionary.
- DDL changes database schema/metadata.
- Examples: `CREATE`, `ALTER`, `DROP`, `TRUNCATE`, `RENAME`.
- DML (`INSERT`, `UPDATE`, `DELETE`) changes data, not metadata.
