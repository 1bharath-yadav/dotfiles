# Personal Neovim extensions

Omarchy owns the base configuration and LazyVim owns the common plugin stack.
This directory is reserved for personal extras and small opt-in overrides only.

Kept extras: Markdown workflow (including Obsidian, preview, image paste, table mode,
and outline), Copilot with Blink integration and CopilotChat, DAP, Neotest, Harpoon,
Spectre search/replace, Yazi integration, tmux navigation, and Tree-sitter text objects/
autotagging.

Intentionally excluded as duplicate/default-managed: Auto Session, nvim-surround,
Bufferline, Flash, Conform, Gitsigns, nvim-lint, Lualine, Persistence, Snacks, core
Tree-sitter, Trouble, and Which-Key.
