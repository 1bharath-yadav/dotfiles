



# Kanata Power-User Usage Guide

## Layer Activation

| Hold Key | Layer | Purpose |
|----------|-------|---------|
| **Space** | Navigation | Arrows, browser shortcuts |
| **Caps Lock** | Navigation | Same as Space navigation |
| **Backspace** | Symbol | Numbers & symbols |
| **Enter** | Apps | Launch apps & media controls |
| **Tab** | **Tap = Tab • Hold = Enter** |

## Home-Row Modifiers

| Key | Tap | Hold |
|-----|-----|------|
| A | a | Ctrl |
| S | s | Alt |
| D | d | Super |
| F | f | Shift |
| J | j | Shift |
| K | k | Super |
| L | l | Alt |
| ; | ; | Ctrl |

## Special Dual-Role Keys

- **Esc:** Tap = Esc, Hold = Left Ctrl
- **Space:** Tap = Space, Hold = Navigation layer
- **Caps:** Hold = Navigation layer
- **Backspace:** Hold = Symbol layer
- **Enter:** Hold = Apps layer
- **Tab:** **Tap = Tab, Hold = Enter**

## Main Productivity Keys

- **Z (hold):** Alt+Tab
- **X (hold):** Alt+`
- **C (hold):** Copy
- **V (hold):** Paste
- **B (hold):** tmux last window
- **M (hold):** tmux paste buffer
- **G (hold):** Undo (Ctrl+Z)

## Navigation Layer

- **H J K L** → ← ↓ ↑ →
- **N / , / . / B** → Browser Back, Next Tab, Previous Tab, Forward
- **R** → Refresh
- **T** → New Tab
- **W** → Close Tab
- **U** → Focus Address Bar
- **I** → Bookmark Page
- **Y** → Reopen Closed Tab

## Apps Layer

- **A:** File Manager
- **F:** VS Code
- **K:** Kitty
- **L:** Brave
- **Enter:** Main Terminal
- **Z:** Yazi
- **X:** Obsidian
- **C:** Calendar
- **V:** Google Keep
- **B:** Tasks
- **N:** Quick Note
- **M:** Gmail
- **,:** Hermes

## Common Chords

- **W+E+R:** Zoom In
- **S+D+F:** Zoom Out
- **Q+W+E:** Volume Up
- **A+S+D:** Volume Down
- **Space+F+G:** Alt+Tab
- **Space+Caps:** Toggle Caps Lock
